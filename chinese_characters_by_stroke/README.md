Characters: U+4E00 through U+9FFF, inclusive.
Source: Unicode 17.0.0 Unihan kTotalStrokes.
https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip

Each text file contains characters with the same standard total stroke count, in Unicode order.
UTF-8; 16 characters per line, except the final line may be shorter.
Alternate stroke counts are not used. Missing counts go in unknown.txt when present.
summary.csv records the number of characters in each file.
