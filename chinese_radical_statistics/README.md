Radical counts for the original 20,992 characters.

radical_statistics.txt and radical_statistics.csv are sorted by decreasing character count.
Radical ID apostrophes are retained, so simplified forms are counted separately.
Ties are ordered by radical number, then form. Percentages use all 20,992 characters.
character_radical_mapping.csv provides the chosen bin and all original classifications for auditing.
The first listed kRSUnicode value is used when multiple classifications exist.

Sources (Unicode 17.0.0, matching the stroke-count files):
https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip
https://www.unicode.org/Public/17.0.0/ucd/CJKRadicals.txt
